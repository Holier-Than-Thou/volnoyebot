# Project instructions

- Before implementing a new bot command, check whether the user explicitly
  specified its access scope.
- If the scope is missing, ask whether the command is available only to the
  administrator from `ADMIN_ID` or to all users. Do not implement it until the
  user answers.
- After every completed project change, run the relevant checks and create a
  Git commit containing that change.
- After completing and testing a logical change, create a focused local Git
  commit. Do not include unrelated user changes and do not push automatically.
