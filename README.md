# Казино «Три топора» — Telegram-бот

Бот работает через отдельный аккаунт Telegram-бота, созданный в `@BotFather`.
В игре используются только виртуальные очки: их нельзя купить, вывести или
обменять на деньги и призы.

## Установка

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Получите `API_ID` и `API_HASH` на `my.telegram.org`, создайте бота в
`@BotFather` и заполните `.env`:

```dotenv
API_ID=123456
API_HASH=ваш_api_hash
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=telegram_id_администратора
SESSION_NAME=casino_bot
```

Для обработки сообщений `кости X`, `+`, `да` и ответов игры «Угадай звук»
отключите Privacy Mode командой `/setprivacy` в `@BotFather` либо назначьте
бота администратором чата.

Запуск:

```powershell
python bot.py
```

## Тесты

Весь набор запускается одной командой из корня проекта:

```powershell
python -m unittest discover -s tests -t .
```

Каталог `tests` — пакет, поэтому команда находит все модули `test_*.py`.
Отдельный файл можно запустить напрямую, добавив корень проекта в путь:

```powershell
$env:PYTHONPATH = "."; python tests/test_casino.py
```

Внешние сервисы в тестах не используются: Telegram, Freesound и Motovskikh
подменяются заглушками, а SQLite создаётся в памяти или во временном каталоге.

Тестовое приватное лобби Motovskikh Tests с подключённым наблюдателем:

```powershell
python scripts/create_motovskikh_lobby.py moscow
```

При первом запуске скрипт отправляет волшебную ссылку на email и ожидает ввода
её кода или полной ссылки в терминале. Затем он проверяет код через API сайта
и при первом входе регистрирует имя `Тестовый бот`. После авторизации он печатает ссылку-приглашение, входит
как `Тестовый бот` в режиме наблюдателя и поддерживает соединение до `Ctrl+C`.
Cookies сохраняются локально в `data/motovskikh.cookies.txt` и не попадают в
Git. Вместо `moscow` можно передать путь другого теста.

## Привязка Motovskikh Tests

В личном чате с ботом команда `/motovskikh_auth` создаёт приватную комнату для
привязки авторизованного аккаунта Motovskikh к Telegram-пользователю. Бот
подключается наблюдателем, определяет постоянный серверный `player.i` и просит
подтвердить найденный аккаунт inline-кнопкой.

Для серверного запуска заранее создайте сервисную сессию скриптом выше и
перенесите файл cookies в каталог данных без добавления в Git. Путь можно
переопределить переменной `MOTOVSKIKH_COOKIE_PATH`. Access-cookie обновляется
автоматически через refresh-cookie.

Привязки хранятся в рабочей SQLite-базе с уникальностью в обе стороны: один
Telegram-пользователь соответствует одному `player.i`, и наоборот. Смена
привязки запрещена при активном вызове или партии со ставкой. Незавершённая
попытка по умолчанию действует 5 минут; количество параллельных комнат
ограничивается переменной `MOTOVSKIKH_MAX_LINK_ATTEMPTS`.

В активированном групповом чате игрок может вызвать соперника командой
`мот [ставка] <ссылка на тест>` или `каз мот [ставка] <ссылка на тест>` —
ответом на сообщение либо с `@тегом`. Соперник принимает вызов ответом `+`
или `да` в течение 60 секунд. Бот создаёт приватную комнату, остаётся в ней
наблюдателем-хостом, исключает посторонних и после финального события сайта
рассчитывает ставку. Команды `мот инфо` и `мот топ` показывают статистику.
Предельная продолжительность матча задаётся переменной
`MOTOVSKIKH_MATCH_TTL_SECONDS` (по умолчанию 3600 секунд); после тайм-аута
зарезервированные ставки возвращаются.

Для серверного запуска конфигурацию и рабочие данные можно хранить отдельно
от Git-репозитория:

```text
ENV_FILE=/etc/volnoyebot/volnoyebot.env
DATA_DIR=/var/lib/volnoyebot
```

При отсутствии этих переменных локальный запуск продолжает использовать
`.env`, SQLite-базы и файл сессии из каталога проекта.

Вход по номеру телефона не требуется. Токен и файл `*.session` нельзя отправлять
другим людям.

После добавления в группу бот игнорирует все сообщения. Для активации
администратор из `ADMIN_ID` должен отправить сообщение с упоминанием бота и
словом `старт`, например:

```text
@three_axes_bot старт
```

## Команды участников

В личном чате доступны slash-команды:

- `/start` — приветствие и краткое описание бота;
- `/help` — актуальный список пользовательских команд;
- `/motovskikh_auth` — привязать аккаунт Motovskikh Tests.

Список устанавливается в Telegram автоматически при запуске бота и появляется
при вводе `/`. Единый реестр меню и текста `/help` находится в
`games/private_commands.py`.

- `каз помощь` — список команд;
- `каз баланс` — текущий баланс; ответом на сообщение — баланс этого игрока;
- `каз 1` или `каз ставка 1` — сделать ставку; минимальная ставка — 1 очко;
- `каз ва-банк` или `каз вабанк` — поставить весь текущий баланс;
- `каз макс 1000` — установить личный максимум ставки казино;
- `каз макс нет` или `каз макс 0` — снять личное ограничение;
- ответить на сообщение: `каз дать 100` — передать пользователю 100 очков;
- `музей` — показать свой музей; ответом на сообщение — музей игрока;
- `музей помощь` — подробные правила, формулы и пример расчёта;
- `музей создать 10 золота Б` — создать статую, вложив 10 золота;
- `музей создать Г 10 золота` — альтернативный порядок аргументов;
- короткие формы золота: `музей создать 10з Б` и `музей создать Б 10 з`;
- `каз деп малышка` — один раз обменять 👩 на 2 000 очков;
- `каз деп мать` — один раз обменять 👵 на 10 000 очков;
- `каз деп тачка` — один раз обменять 🚗 на 25 000 очков;
- `каз деп хата` — один раз обменять 🏠 на 100 000 очков;
- `каз призы` — комбинации и множители;
- `каз топ` — балансы всех игроков, помещающихся в одно сообщение;
- `каз топ RTP` — игроки по убыванию фактического RTP казино;
- `каз топ RTP возр` — игроки по возрастанию фактического RTP казино;
- `каз лог` — последние 10 игр и операций текущего пользователя;
- `каз лог все` — последние 10 игр и операций всего чата.
- `каз аналитика` — показать оборот, выплаты, прибыль казино и фактический RTP;
- ответить на сообщение командой `каз аналитика` — показать личную статистику
  пользователя отдельно по казино и костям.
- `каз ферма` — показать специализацию, питомцев и накопленный доход;
  ответом на сообщение — ферму этого игрока;
- `каз ферма собрать` — перевести накопленный доход на баланс;
- `каз ферма дать N` — предложить питомца или яйцо пользователю, ответив
  командой на его сообщение;
- `каз ферма приют N` — отдать питомца или яйцо из слота в приют;
- `каз ферма переименовать N Имя` — переименовать взрослого питомца;
- `каз скрестить N N` — заменить двух взрослых родителей яйцом ребёнка.

Новые игроки и пользователи без истории казино и костей могут передавать
очки другим игрокам только через 24 часа после своей первой команды.

## Музей

Золото выдаётся только при ставке ва-банк: 1 золото за каждые полные
100 000 очков ставки вне зависимости от выигрыша. При комбинации ровно из
двух 7️⃣ золото не начисляется. Текущий запас золота отображается в
`каз баланс`.

Размер статуи задаётся буквой:

- `Б` — большая, базовый доход 9 000 очков/сутки, коэффициент золота 2;
- `Г` — гигантская, базовый доход 30 000 очков/сутки, коэффициент золота 1;
- `В` — великая, базовый доход 75 000 очков/сутки, коэффициент золота 0,5.

При создании всё указанное золото списывается. Результат равен случайному
целому числу от 1 до 100 плюс целочисленный бонус золота. Для Великой статуи
каждые две дополнительные единицы золота дают один полный балл, поэтому
дробных результатов не возникает.

При результате ниже 71 заготовка ломается: золото расходуется, но статуя не
появляется. Успешное качество умножает базовый доход: нормальное ×1,
хорошее ×2, отличное ×5, шедевр ×10. Доходы всех статуй складываются и
начисляются за каждые завершённые сутки, но суммарное начисление музея
ограничено 300 000 очков в сутки. Статуи и их характеристики при достижении
лимита не изменяются.

Все команды фермы можно вызывать без префикса `каз`: `ферма`,
`ферма собрать`, `ферма дать N`, `ферма приют N`,
`ферма переименовать N Имя` и
`ферма скрестить N N`. Общий префикс `ферма` будет использоваться и для
будущих команд этой игры.

Каждые 30 минут бот начисляет игрокам активированных чатов, которые
использовали хотя бы одну команду бота за последние 3 суток,
по 1 000 очков. Сообщение в чат отправляется только при наличии получателей
с нулевым балансом. Первое начисление после установки
этого обновления выполняется сразу после запуска бота, но пользователи без
истории игр начнут получать зарплату только после своей первой команды.
Расписание хранится в базе данных и сохраняется после перезапуска. Начисления
отображаются в `каз лог` и `каз лог все`.

В основном топике уведомления включены по умолчанию. В дополнительных топиках
они включаются отдельно командой `каз уведы`. Если топиков в чате нет, команда
управляет единственным общим каналом уведомлений. Уведомление о зарплате
отправляется только при наличии активных игроков с нулевым балансом и дополнительно
упоминает не более 10 игроков, у которых перед начислением было 0 очков:
сначала тех, кто играл позднее.

После установки новой версии бот один раз публикует краткую сводку изменений
в каждом активном разделе и пытается её закрепить. Повторные перезапуски той же
версии не создают дубликаты: отправленные версии хранятся в SQLite. Если у бота
нет права закреплять сообщения, ошибка выводится только в консоль. При следующем
пользовательском обновлении разработчику нужно изменить `RELEASE_ID` и
`RELEASE_SUMMARY` в `games/release.py`.

### Игра в кости

Чтобы вызвать пользователя на игру, ответьте на его сообщение:

```text
кости 500
```

Бот отправит предложение сыграть на 500 очков. Только вызванный пользователь
может принять его, ответив на предложение `+` или `да`. После принятия у обоих
игроков атомарно списывается ставка и отправляются два серверных кубика `🎲`.
Первый кубик относится к вызвавшему игроку, второй — к принявшему. Победитель
получает общий банк. При одинаковых значениях кубики автоматически перебрасываются.
Вызов действует 60 секунд. Если соперник не ответил, предложение удаляется,
а вызов получает статус `expired`; деньги при этом не списываются.

Анимация одного кубика длится 3 секунды по данным официального TGS-набора
Telegram; сообщение с результатом отправляется после завершения анимации.

Через 5 секунд после итогового сообщения одновременно удаляются кубики, принятое
предложение, сообщения о ничьих и итог игры. Пользовательские сообщения не
удаляются.

## Команды администратора

Администратор определяется переменной `ADMIN_ID` в `.env`.

- `каз раздать` — показать число уже известных боту пользователей; новый
  пользователь автоматически получает начальный баланс при первом обращении;
- `каз сброс` — сбросить балансы всех доступных участников чата;
- ответить на сообщение: `каз выдать 500` — начислить 500 очков автору;
- ответить на сообщение: `каз выдать 2 з` — выдать автору 2 золота;
- ответить на сообщение: `каз установить 500` — установить баланс автору;
- `каз выдать 123456789 500` — начислить по Telegram ID;
- `каз выдать 123456789 2 з` — выдать золото по Telegram ID;
- `каз установить 123456789 500` — установить по Telegram ID.
- `каз стоп` — остановить казино и кости в текущем разделе чата;
- `каз старт` — запустить казино и кости в текущем разделе чата;
- `каз автоудаление` — включить или выключить автоудаление в текущем чате;
- `каз уведы` — включить или выключить периодические уведомления в текущем
  топике;
- `каз зп` — немедленно начислить всем известным игрокам текущего чата по
  1 000 очков и отправить уведомление;
- `кз кд 20` или `каз кд 20` — установить кулдаун казино в секундах;
- `кз кд 0` — отключить кулдаун для обычных пользователей.

Команды работают только в группах и супергруппах. Telegram Bot API не позволяет
получить полный список участников, поэтому бот узнаёт пользователей по мере их
обращения.
Сообщения с метаданными пересылки Telegram полностью игнорируются и не могут
запускать команды или игровые действия бота.
По умолчанию верхнего лимита ставки нет: она ограничена только текущим балансом
пользователя. Каждый игрок может установить личный предел командой `каз макс Х`.
Обычная ставка выше предела отклоняется. Ва-банк также не выполняется, если
текущий баланс превышает установленный предел.
По умолчанию между ставками одного пользователя должно пройти 20 секунд.
Администратор может изменить значение отдельно для каждого чата. На аккаунт
администратора кулдаун не распространяется при любом значении настройки.
В основном разделе казино и кости включены по умолчанию, в дополнительных
топиках — выключены. Состояние каждого раздела сохраняется после перезапуска.
Доступные одноразовые ресурсы отображаются эмодзи в команде `каз баланс`.
Обменянный ресурс не восстанавливается при административном сбросе баланса.

## Правила выплат

Ставка списывается перед вращением. Бот отправляет нативный анимированный
Telegram-слот `🎰`, ждёт около 2,4 секунды и рассчитывает выплату по серверному
результату Telegram:

- `7️⃣ 7️⃣ 7️⃣` — ×30;
- `BAR BAR BAR` — ×10;
- `🍒 🍒 🍒` — ×10;
- `🍋 🍋 🍋` — ×4;
- ровно две `7️⃣` — ×1, то есть возврат ставки.

Ровно две `🍒` дополнительно дают яйцо для фермы, если у игрока есть свободный
слот. Тройная комбинация `🍒 🍒 🍒` остаётся денежным выигрышем и яйцо не даёт.

Выигрышная выплата равна `ставка × множитель`. Теоретический RTP этой таблицы —
`63 / 64 = 98,4375%`, преимущество казино — `1,5625%`. Telegram генерирует
одно из 64 значений на своей стороне; бот не выбирает результат самостоятельно.

## Ферма питомцев

У каждого игрока при первом обращении к ферме навсегда выбирается специализация:
💨 вонь, 🤢 уродство или 🍯 липкость. На ферме шесть слотов. Полученное из
слота казино яйцо созревает случайное целое число минут от 5 до 60 и затем
вылупляется автоматически. До вылупления его специализация, происхождение и
гены полностью скрыты. При вылуплении питомец получает случайное имя из
`data/pet_names.txt`.

Чистопородный питомец имеет только один ненулевой признак своей специализации.
Нулевой признак не может самостоятельно появиться у его потомства. Двух
взрослых чистопородных питомцев можно скрестить: родители исчезают, а в младшем
из выбранных слотов появляется яйцо. Потомок одной специализации остаётся
чистопородным и получает небольшое положительное математическое ожидание
мутации. При скрещивании разных специализаций получается многопризнаковый
стерильный гибрид.

Взрослые питомцы непрерывно приносят виртуальные очки. Для двух и трёх активных
признаков действуют коэффициенты синергии ×1,35 и ×1,80. Команда фермы
показывает общий доход в секунду, час и сутки. Накопления забираются командой
`ферма собрать`; дробный остаток сохраняется.

Чтобы передать питомца или яйцо, нужно ответить на сообщение получателя
командой `ферма дать N`. Получатель подтверждает передачу ответом `+` или `да`
на предложение бота в течение 60 секунд. Для принятия необходим свободный слот.
На время предложения питомец резервируется и не может быть отдан в приют либо
использован в скрещивании. Все команды фермы доступны обычным игрокам в
разделах, где казино запущено.

При проигрыше слот-эмодзи и текст результата одновременно удаляются через
5 секунд после результата. При выигрыше и слот-эмодзи, и сообщение о результате
остаются в чате. Все завершённые ставки, партии в кости, переводы, выдачи и
установки баланса сохраняются в журнале SQLite. Успешные уведомления о переводе,
выдаче и установке баланса удаляются через 5 секунд.

Автоудаление по умолчанию включено и настраивается отдельно для каждого чата.
Настройка сохраняется после перезапуска. Если автоудаление выключено, истёкшие
вызовы в кости всё равно закрываются, но их сообщения остаются в чате.

## Структура проекта

- `bot.py` — запуск, конфигурация, общее хранилище очков и команды управления;
- `games/casino.py` — правила слота и регистрация команды `каз`;
- `games/dice.py` — полный сценарий вызова и игры в кости.

Игровые модули подключаются через функцию `register`. Игра «Угадай звук»
размещена в отдельном пакете `games/guess_sound` и не смешивает своё состояние
с казино или костями.

## Браузерный прототип «Крокодила»

Frontend-прототип находится в каталоге `webapp`. Он пока не подключён к
Telegram и серверу: переключатель «Смотреть как» имитирует разных участников
одной игровой комнаты.

```powershell
Set-Location webapp
npm.cmd install
npm.cmd run dev
```

Для проверки production-сборки:

```powershell
npm.cmd run build
```

## Браузерный прототип рыбалки

Рыбалка добавлена как отдельная страница того же автономного frontend-проекта.
Она пока не подключена к Telegram, боту или базе данных.

```powershell
Set-Location webapp
npm.cmd install
npm.cmd run dev
```

После запуска откройте адрес, напечатанный Vite, добавив к нему
`/fishing.html`, например `http://localhost:5173/fishing.html`.

В мини-игре удерживайте левую кнопку мыши, палец на экране или пробел, чтобы
поднимать маркер; отпускайте, чтобы он опускался.

Пиксель-арт фон и спрайтовый лист рыбака находятся в
`webapp/public/assets/fishing`. Это оригинальные ассеты прототипа, а не графика
из сторонней игры.

## Игра «Угадай звук»

Для игры нужен ключ приложения Freesound. Получите его на
<https://freesound.org/apiv2/apply> и задайте в `.env`:

```dotenv
FREESOUND_API_KEY=ваш_ключ
```

Команды:

- `зг` — краткая справка;
- `зг старт` — начать раунд со случайной BST-тематикой;
- `зг старт fx-o` — начать раунд с указанной BST-тематикой; доступно
  администратору;
- `зг инфо` — показать свою статистику;
- `зг инфо` ответом на сообщение — статистика автора сообщения;
- `зг топ` — десять лучших игроков текущего чата;
- `зг стоп` — отменить текущий раунд; доступно администратору.

На предположения и голосование даётся по одной минуте. Ответ нужно отправить
ответом на аудиосообщение. Принимается первый ответ пользователя. В опрос
попадают первые 11 уникальных вариантов; совпадения после нормализации
объединяются. Опрос неанонимный и допускает несколько вариантов. Голоса авторов
за собственный вариант не учитываются при подсчёте. Бот накапливает события
голосования в реальном времени, включая множественный выбор, изменение и отзыв
голоса; запрещённый для bot-аккаунтов запрос полного списка голосовавших не
используется.

Используются MP3-превью Freesound длительностью 3–20 секунд с лицензией CC0,
исключая explicit-контент. Для обычного запуска равновероятно выбирается одна
из BST-категорий: `fx-o`, `fx-v`, `fx-m`, `fx-h`, `fx-a`, `fx-n`.
Администратор может указать одну из них явно после `зг старт`. Перед отправкой
метаданные удаляются, имя файла заменяется на `audio.mp3`. История
использованных звуков и статистика хранятся отдельно от казино в
`guess_sound.sqlite3`. Активные раунды после перезапуска не восстанавливаются.

Код игры находится в `games/guess_sound`. Telegram-сценарий работает через
абстракцию источника звуков; Freesound подключён отдельным адаптером
`freesound.py`.
