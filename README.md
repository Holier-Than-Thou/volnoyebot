# Казино «Три топора» — Telegram-бот

Бот работает через отдельный аккаунт Telegram-бота, созданный в `@BotFather`.
В игре используются только виртуальные очки: их нельзя купить, вывести или
обменять на деньги и призы.

## Установка

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Получите `API_ID` и `API_HASH` на `my.telegram.org`, создайте бота в
`@BotFather` и заполните `.env`:

```dotenv
API_ID=123456
API_HASH=ваш_api_hash
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=telegram_id_администратора
SESSION_NAME=casino_bot
```

Для обработки сообщений `кости X`, `+`, `да` и ответов игры «Угадай звук»
отключите Privacy Mode командой `/setprivacy` в `@BotFather` либо назначьте
бота администратором чата.

Запуск:

```powershell
python bot.py
```

Вход по номеру телефона не требуется. Токен и файл `*.session` нельзя отправлять
другим людям.

После добавления в группу бот игнорирует все сообщения. Для активации
администратор из `ADMIN_ID` должен отправить сообщение с упоминанием бота и
словом `старт`, например:

```text
@three_axes_bot старт
```

## Команды участников

- `каз помощь` — список команд;
- `каз баланс` — текущий баланс;
- `каз 100` или `каз ставка 100` — сделать ставку;
- `каз ва-банк` или `каз вабанк` — поставить весь текущий баланс;
- ответить на сообщение: `каз дать 100` — передать пользователю 100 очков;
- `каз деп малышка` — один раз обменять 👩 на 2 000 очков;
- `каз деп мать` — один раз обменять 👵 на 10 000 очков;
- `каз деп тачка` — один раз обменять 🚗 на 25 000 очков;
- `каз деп хата` — один раз обменять 🏠 на 100 000 очков;
- `каз призы` — комбинации и множители;
- `каз топ` — десять крупнейших балансов чата;
- `каз лог` — последние 10 игр и операций текущего пользователя;
- `каз лог все` — последние 10 игр и операций всего чата.

Каждые 30 минут бот начисляет всем известным игрокам активированных чатов
по 1 000 очков и сообщает об этом в чат. Первое начисление после установки
этого обновления выполняется сразу после запуска бота (либо после первой
активации чата, если активных чатов ещё нет). Расписание хранится в базе данных
и сохраняется после перезапуска. Начисления отображаются в `каз лог` и
`каз лог все`.

В основном топике уведомления включены по умолчанию. В дополнительных топиках
они включаются отдельно командой `каз уведы`. Если топиков в чате нет, команда
управляет единственным общим каналом уведомлений. В сообщении бот дополнительно
упоминает не более 10 игроков, у которых перед начислением было 0 очков:
сначала тех, кто играл позднее.

### Игра в кости

Чтобы вызвать пользователя на игру, ответьте на его сообщение:

```text
кости 500
```

Бот отправит предложение сыграть на 500 очков. Только вызванный пользователь
может принять его, ответив на предложение `+` или `да`. После принятия у обоих
игроков атомарно списывается ставка и отправляются два серверных кубика `🎲`.
Первый кубик относится к вызвавшему игроку, второй — к принявшему. Победитель
получает общий банк. При одинаковых значениях кубики автоматически перебрасываются.
Вызов действует 60 секунд. Если соперник не ответил, предложение удаляется,
а вызов получает статус `expired`; деньги при этом не списываются.

Анимация одного кубика длится 3 секунды по данным официального TGS-набора
Telegram; сообщение с результатом отправляется после завершения анимации.

Через 5 секунд после итогового сообщения одновременно удаляются кубики, принятое
предложение, сообщения о ничьих и итог игры. Пользовательские сообщения не
удаляются.

## Команды администратора

Администратор определяется переменной `ADMIN_ID` в `.env`.

- `каз раздать` — показать число уже известных боту пользователей; новый
  пользователь автоматически получает начальный баланс при первом обращении;
- `каз сброс` — сбросить балансы всех доступных участников чата;
- ответить на сообщение: `каз выдать 500` — начислить 500 очков автору;
- ответить на сообщение: `каз установить 500` — установить баланс автору;
- `каз выдать 123456789 500` — начислить по Telegram ID;
- `каз установить 123456789 500` — установить по Telegram ID.
- `каз стоп` — приостановить обработку новых команд в текущем чате;
- `каз старт` — возобновить работу в текущем чате;
- `каз автоудаление` — включить или выключить автоудаление в текущем чате;
- `каз уведы` — включить или выключить периодические уведомления в текущем
  топике;
- `каз аналитика` — показать оборот, выплаты, прибыль казино и фактический RTP;
- ответить на сообщение командой `каз аналитика` — показать личную статистику
  пользователя отдельно по казино и костям;
- `каз зп` — немедленно начислить всем известным игрокам текущего чата по
  1 000 очков и отправить уведомление;
- `кз кд 20` или `каз кд 20` — установить кулдаун казино в секундах;
- `кз кд 0` — отключить кулдаун для обычных пользователей.

Команды работают только в группах и супергруппах. Telegram Bot API не позволяет
получить полный список участников, поэтому бот узнаёт пользователей по мере их
обращения.
Верхнего лимита ставки нет: она ограничена только текущим балансом пользователя.
По умолчанию между ставками одного пользователя должно пройти 20 секунд.
Администратор может изменить значение отдельно для каждого чата. На аккаунт
администратора кулдаун не распространяется при любом значении настройки.
Состояние остановки каждого чата сохраняется после перезапуска бота.
Доступные одноразовые ресурсы отображаются эмодзи в команде `каз баланс`.
Обменянный ресурс не восстанавливается при административном сбросе баланса.

## Правила выплат

Ставка списывается перед вращением. Бот отправляет нативный анимированный
Telegram-слот `🎰`, ждёт около 2,4 секунды и рассчитывает выплату по серверному
результату Telegram:

- `7️⃣ 7️⃣ 7️⃣` — ×30;
- `BAR BAR BAR` — ×10;
- `🍒 🍒 🍒` — ×10;
- `🍋 🍋 🍋` — ×4;
- ровно две `7️⃣` — ×1, то есть возврат ставки.

Выигрышная выплата равна `ставка × множитель`. Теоретический RTP этой таблицы —
`63 / 64 = 98,4375%`, преимущество казино — `1,5625%`. Telegram генерирует
одно из 64 значений на своей стороне; бот не выбирает результат самостоятельно.

При проигрыше слот-эмодзи и текст результата одновременно удаляются через
5 секунд после результата. При выигрыше и слот-эмодзи, и сообщение о результате
остаются в чате. Все завершённые ставки, партии в кости, переводы, выдачи и
установки баланса сохраняются в журнале SQLite. Успешные уведомления о переводе,
выдаче и установке баланса удаляются через 5 секунд.

Автоудаление по умолчанию включено и настраивается отдельно для каждого чата.
Настройка сохраняется после перезапуска. Если автоудаление выключено, истёкшие
вызовы в кости всё равно закрываются, но их сообщения остаются в чате.

## Структура проекта

- `bot.py` — запуск, конфигурация, общее хранилище очков и команды управления;
- `games/casino.py` — правила слота и регистрация команды `каз`;
- `games/dice.py` — полный сценарий вызова и игры в кости.

Игровые модули подключаются через функцию `register`. Игра «Угадай звук»
размещена в отдельном пакете `games/guess_sound` и не смешивает своё состояние
с казино или костями.

## Игра «Угадай звук»

Для игры нужен ключ приложения Freesound. Получите его на
<https://freesound.org/apiv2/apply> и задайте в `.env`:

```dotenv
FREESOUND_API_KEY=ваш_ключ
```

Команды:

- `зг` — краткая справка;
- `зг старт` — начать раунд со случайной BST-тематикой;
- `зг старт fx-o` — начать раунд с указанной BST-тематикой; доступно
  администратору;
- `зг инфо` — показать свою статистику;
- `зг инфо` ответом на сообщение — статистика автора сообщения;
- `зг топ` — десять лучших игроков текущего чата;
- `зг стоп` — отменить текущий раунд; доступно администратору.

На предположения и голосование даётся по одной минуте. Ответ нужно отправить
ответом на аудиосообщение. Принимается первый ответ пользователя. В опрос
попадают первые 11 уникальных вариантов; совпадения после нормализации
объединяются. Опрос неанонимный и допускает несколько вариантов. Голоса авторов
за собственный вариант не учитываются при подсчёте. Бот накапливает события
голосования в реальном времени, включая множественный выбор, изменение и отзыв
голоса; запрещённый для bot-аккаунтов запрос полного списка голосовавших не
используется.

Используются MP3-превью Freesound длительностью 3–20 секунд с лицензией CC0,
исключая explicit-контент. Для обычного запуска равновероятно выбирается одна
из BST-категорий: `fx-o`, `fx-v`, `fx-m`, `fx-h`, `fx-a`, `fx-n`.
Администратор может указать одну из них явно после `зг старт`. Перед отправкой
метаданные удаляются, имя файла заменяется на `audio.mp3`. История
использованных звуков и статистика хранятся отдельно от казино в
`guess_sound.sqlite3`. Активные раунды после перезапуска не восстанавливаются.

Код игры находится в `games/guess_sound`. Telegram-сценарий работает через
абстракцию источника звуков; Freesound подключён отдельным адаптером
`freesound.py`.
